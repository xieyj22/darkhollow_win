# 暗渊深处(Depths of Darkhollow)— 世界观设定

> 本文档把游戏既有元素(8 区域 / 8 boss / 职业 / 圣物 / 元素 / 秘境 / 无尽)整合进一条连贯叙事,并新增核心剧情(创世者反转、守渊人宿敌、封印-无尽因果)。作为「剧情嵌入游戏 + 玩法派生」的内容基底。

## 核心概念

- **一句话钩子**:你不是来征服暗渊的——你是来**杀死那个守护它的人**,而那个人**一直在等死**。
- **世界类型**:暗黑奇幻(地牢下行 / 程序化 roguelike)。
- **尺度**:单次「下探」(the Descent)——从地表裂口直抵深渊心脏的垂直旅程。
- **基调**:压抑、悲剧、道德灰色;胜利即诅咒。

## 世界的真相(核心反转)

**暗渊(The Abyss)不是地牢,是一道现实的伤口**——千年前从虚空中裂开的溃口,不断吞噬地表。上古诸神无力愈合它,只能**封印**:他们选中一位同伴(后来的「创世者」),将其化作封印的**活心**,镇压在伤口最深处。

千年过去,创世者与深渊同化、永生不灭、痛苦不堪。Ta **从未堕落**,只是累了——**Ta 渴望被杀**:唯有击碎封印之心(即 Ta 自己),封印才会瓦解。但封印一碎,真正的深渊便会从裂口涌出。

于是:每个被派下来的「下探者」,其实都在**替创世者完成一场迟到千年的自杀**,代价是亲手揭开盖住末日的盖子。普通模式的「胜利」是悲剧性的——你完成了任务,也把自己葬入了永无止境的深处(→ F41+ 无尽模式,即封印破碎后涌出的真深渊)。

## 地理与环境(下行八层 = 封印的八道伤痕)

下行不是「越走越深」,而是**穿越封印逐层崩坏的过程**——每个区域是封印的一道裂痕,越深越接近创世者之心。

| 层 | 区域 | 叙事定位 |
|----|------|----------|
| F1-5 | **地下洞穴 The Caverns** | 裂口地表,新下探者的坟场。潮湿、原始,浅层腐化生物(鼠/蝠/哥布林)。 |
| F6-10 | **远古墓穴 Ancient Crypts** | 第一代试图封印深渊的文明的**葬地**。他们失败了,化为亡灵守墓。 |
| F11-15 | **灼热深渊 Burning Depths** | 当年**锻造封印的熔炉**,如今炉裂、地火外泄。火元素生物是封印碎片泄漏的具象。 |
| F16-20 | **暗黑堡垒 Dark Fortress** | **守印者军团**的驻地——他们世代戍守封印,最终全员被腐化为不死/狂化。 |
| F21-25 | **龙之领域 Dragon's Domain** | 守印者驯养的**巨兽**,封印松动后野化、扭曲,在此称王。 |
| F26-30 | **无尽深渊 The Abyss** | 封印裂缝已大,深渊的**本体**开始渗入。海水深不可测,有东西在下方注视。 |
| F31-35 | **虚空领域 Void Realm** | 现实在此崩坏——封印的裂纹扭曲了时空,「不该存在的颜色」刺痛双眼。 |
| F36-40 | **最终圣殿 The Final Sanctum** | 封印的**心脏**、创世者的囚笼与王座。神圣光芒是 Ta 千年未熄的意志。 |
| (秘境) | **荧光菌穴 Fungal Hollow** | 深渊的**免疫系统**——一团活着的菌丝意识,会吞噬闯入者。经传送门偶入。 |
| F41+ | **无尽深渊 Endless** | 封印破碎后涌出的**真深渊**。没有底。你亲手放出的东西。 |

## 种族与文明

- **地表诸国(the Surface)**:裂口边缘的人类文明。他们组织**「下探者公会」(Descender's Guild)**,持续派遣冒险者下探——表面理由是「击败创世者、终结暗渊之患」,但公会高层**隐约知晓真相**(封印碎裂的代价),只是对下层隐瞒。
- **下探者(Descenders)**:玩家所属。每次下探都是单程票般凶险;绝大多数有去无回,或如守渊人般被吞噬。
- **腐化者(the Corrupted)**:被深渊同化的生灵(大部分敌人)。它们曾是守印者、巨兽、冒险者,如今只剩本能与怨念。
- **中立存在**:流浪商人(也是下探者,选择留在深渊做买卖)、菌主(菌穴意识核心)、失忆的远古残神。

## 力量体系(游戏机制 → 叙事)

- **元素(火/冰/雷/暗/圣)**:封印的五道**纹理**。深渊泄漏的是「暗」,守印者残留的是「圣」,元素生物是泄漏的具象。玩家法术 = 短暂借用纹理之力。
- **圣物(Relics)**:封印的**碎片**与创世者昔日的**随身之物**。每一件都带着一段被遗忘的记忆(→ 圣物图鉴可展开 lore)。
- **天赋(Talents)/ 职业(战/贼/法/骑)**:下探者公会传承的训练体系。每个职业下探的理由不同(见百科)。
- **限制(代价)**:力量来自深渊的泄漏——用得越深,越易被深渊「记住」(叙事上为「腐化」机制留口子;玩法上可派生腐化度/理智值)。

## 阵营与势力

| 阵营 | 目标 | 与玩家关系 |
|------|------|-----------|
| **下探者公会(地表)** | 维持封印 / 或暗图利用破碎 | 派遣你、给你天赋与补给;高层动机存疑。 |
| **创世者** | **求死**(终结千年守护) | 默默等待、甚至**指引**你下探。最终对手,却是盟友。 |
| **深渊意志** | 撕开封印、吞噬地表 | 通过腐化者、守渊人阻杀下探者。 |
| **守印者残部(亡灵)** | 执行千年前的戍守命令(已疯) | 敌对,但部分尚存守护本能。 |
| **中立者(商人/菌主)** | 自保 | 可交易/可避免冲突。 |

## 主线脉络(贯穿下探)

1. **下探**(F1-25):你以为自己是来「终结暗渊」的英雄。沿途守印者残部、巨兽阻杀你;公会情报称「击败创世者即可拯救世界」。
2. **疑云**(F26-35):深渊深处,你开始捡到**创世者的记忆碎片**(圣物/刻文)——Ta 不是恶神,是被囚的守护者;「击败 Ta 会发生什么」的疑问升起。
3. **真相**(F36-40):最终圣殿,创世者以残躯相迎,道出真相并**请你去死**(求你杀 Ta)。击败 Ta = 碎封印。
4. **结局分叉**:
   - **普通模式**:封印碎裂的一刻,你以为胜利——但脚下裂开真正的深渊。胜利屏带讽刺:你完成了任务,也打开了末日。
   - **无尽模式(F41+)**:你坠入碎封后的真深渊,没有终点,只有一层比一层深的悔恨与求生。死亡即结算——你成了下一个「差点成功」的下探者,你的记录会被后来者(与守渊人)看到。

## 守渊人(The Warden)— 宿敌机制(玩法派生核心)

- **设定**:一个曾经下探到极深、失败后被深渊吞噬的前代冒险者。深渊没有杀死 Ta,而是**把 Ta 改造成了免疫系统**——如今 Ta 是深渊的猎犬,专门追杀下探者。Ta 还保留着残破的人性(偶尔会在战斗中闪回自己的记忆)。
- **玩法派生**:守渊人**周期性跨层追猎**——每下探 N 层(如每 8-10 层,或累计击杀达阈值),Ta 会现身一战。越深越强(随 fs 缩放),且每次击退 Ta 会掉落一件**「前任下探者的遗物」**(独特圣物 + 一段 Ta 的记忆 lore)。Ta 是除固定 boss 外的**动态威胁**——你不知道 Ta 何时出现,只能在下探中时刻提防。
- **叙事钩子**:守渊人就是「失败的你」——若你在无尽模式死去,理论上你会成为下一个守渊人(呼应记录表/排行榜:你的失败 run 化作了深渊的一部分)。

## 内在矛盾(故事引擎)

1. **任务 vs 真相**:公会要你「杀创世者」,但杀 = 放出深渊。你是在拯救世界,还是在执行末日的最后一步?
2. **慈悲 vs 代价**:创世者求死是慈悲,但代价是整个地表。你给不给 Ta 这个解脱?
3. **胜利即诅咒**:通关不是救赎,是更深的坠落(无尽模式)。「赢」的定义被动摇。
4. **你 vs 守渊人**:你们曾是同路人。击败 Ta 是自保,还是预演自己未来的失败?
5. **公会的隐瞒**:高层知道真相却仍派人下探——他们是救世者,还是把冒险者当耗材的算计者?

## 未解之谜(留给游戏/续作揭示)

- 创世者的真名与生前样貌(圣物碎片逐步揭露)。
- 公会高层究竟知多少?是否有人在**故意**碎封印?
- 深渊之下(F100+ 极深处)是否还有别的东西——比深渊更古老的存在?
- 守渊人曾下探到多深?Ta 的遗物藏着怎样的前任旅程?
- 第一代封印文明的覆灭细节(墓穴/熔炉的刻文)。

## 玩法派生清单(从剧情 → 机制,供后续 Wave)

1. **守渊人周期追猎系统**(最高优先):动态宿敌遭遇 + 掉落「前任遗物」(lore 圣物)。
2. **📜 典籍/日志面板**:解锁式 lore 条目(背景/区域/boss/圣物/守渊人记忆),复用 records 面板模式。
3. **剧情消息**:下楼到新区/捡圣物/遇守渊人时弹叙事消息(从既有 area.lore 扩展)。
4. **圣物记忆**:每件圣物带一段 lore,拾取时解锁一条典籍。
5. **(远期)腐化度/理智值**:用深渊之力越深越接近成为下一个守渊人。
6. **(远期)公会抉择**:结局处可选「杀创世者(碎封印→无尽)」或「拒绝(背负创世者继续守护)」——多结局。
