# 暗渊深处 — 世界观百科(Glossary)

> 关键概念词条。每条:一句话定义 + 详细描述 + 故事/玩法钩子。供「典籍/日志面板」直接取用。

---

## 核心设定

### 暗渊(The Abyss / 暗渊)
- **定义**:裂开在地表的一道**现实伤口**,千年不断吞噬世界。
- **描述**:不是物理意义的洞穴,而是存在本身的溃烂。越深,现实越稀薄、腐化越重。它的「免疫细胞」会吞噬一切闯入者。
- **钩子**:深渊是**活的**——它会学习、会记住下探者(守渊人即是被它记住并改造的)。F41+ 无尽模式 = 你打碎封印后它涌出的本体。

### 创世者(The Creator / 创世者)
- **定义**:千年前被诸神化作**封印活心**的英雄,永生镇守暗渊。
- **描述**:与深渊同化千年,肉体枯朽、意识残存。Ta 从未堕落——只是累了。Ta **渴望被杀**:唯有击碎封印之心(Ta 自己)封印才会瓦解。最终圣殿的圣光,是 Ta 千年未熄的意志。
- **钩子**:真正的反派不是 Ta,是**深渊本身**。「击败创世者」= 替 Ta 完成迟到千年的自杀,代价是放出真深渊。→ 普通模式胜利的悲剧性。

### 封印(The Seal / 封印)
- **定义**:以创世者为活心、镇压暗渊的千年禁制。
- **描述**:由第一代文明(墓穴/熔炉的建造者)与诸神合力铸成。八层下行区域即封印的八道逐层崩坏的伤痕。守印者军团曾世代戍守,如今已全部腐化。
- **钩子**:圣物 = 封印碎片 / 创世者遗物;元素之力 = 封印纹理的泄漏。封印的完整度可作隐藏数值。

### 守渊人(The Warden / 守渊人)
- **定义**:被深渊吞噬、改造成**免疫系统猎犬**的前代下探者。
- **描述**:Ta 曾和你一样下探到极深,失败后被深渊同化而非杀死,化作追杀一切下探者的存在。仍保留残破人性,战斗中偶闪回自己的记忆。
- **钩子**:**周期性跨层追猎**(每 N 层一战,越深越强)→ 动态宿敌机制;掉落「前任遗物」(独特圣物 + 一段 Ta 的记忆 lore)。Ta 是「失败的你」——你的死亡 run 理论上会化作下一个守渊人(呼应排行榜)。

### 下探者公会(Descender's Guild / 下探者公会)
- **定义**:地表诸国组织、持续派遣冒险者下探暗渊的机构。
- **描述**:给下探者训练(职业/天赋)与补给。表面口号「击败创世者、终结暗渊」,但**高层隐约知晓碎封印的代价**,却仍派人——是把冒险者当救世者,还是当耗材?存疑。
- **钩子**:公会的隐瞒是主线的政治悬念;可在圣殿结局处揭露/抉择。

## 区域(下行八层 + 秘境 + 无尽)

### 地下洞穴(The Caverns / 地下洞穴)F1-5
裂口地表,新下探者的坟场。浅层腐化生物(鼠/蝠/哥布林/史莱姆)横行。潮湿、原始,腐化最浅。

### 远古墓穴(Ancient Crypts / 远古墓穴)F6-10
第一代试图封印深渊的**失败文明的葬地**。亡灵守墓者(骷髅/蜘蛛/食人魔)执行千年前的戍守残令。

### 灼热深渊(Burning Depths / 灼热深渊)F11-15
当年**锻造封印的熔炉**所在地。炉裂、地火外泄,火元素生物是封印碎片泄漏的具象。火把/岩浆 tile = 余烬。

### 暗黑堡垒(Dark Fortress / 暗黑堡垒)F16-20
**守印者军团**的驻地。世代戍守封印的战士,最终全员被腐化为不死/狂化。警报锣是他们的遗物。

### 龙之领域(Dragon's Domain / 龙之领域)F21-25
守印者驯养的**巨兽**封印松动后野化、扭曲之地。龙曾是守护者的坐骑,如今嗜血称王。

### 无尽深渊(The Abyss / 无尽深渊)F26-30
封印裂缝已大,深渊**本体**开始渗入。海水深不可测,「有东西在下方注视」。深潜者/海妖/克拉肯是它的延伸。

### 虚空领域(Void Realm / 虚空领域)F31-35
封印裂纹扭曲了时空。现实在此崩坏,「不该存在的颜色」刺痛双眼。虚空生物从裂缝中渗出。

### 最终圣殿(The Final Sanctum / 最终圣殿)F36-40
封印的**心脏**、创世者的囚笼与王座。神圣光芒是创世者千年未熄的意志。炽天使/执政官是 Ta 残存意志的具象守卫。

### 荧光菌穴(Fungal Hollow / 荧光菌穴)— 秘境
深渊**免疫系统**的一处活体袋囊。菌丝意识(菌主)会吞噬闯入者。经传送门偶入,有专属敌 + 迷你 boss + 奖励。

### 无尽深渊(Endless / 无尽深渊)F41+
封印破碎后涌出的**真深渊**。没有底。你亲手放出的东西。专属强敌(虚空泰坦/末日炽天使/熵兽/深渊暴君)是真深渊的原生存在。

- **F5 哥布林王**:裂口地表的 petty 暴君,与主线无关(早期小角色)。
- **F10 蜘蛛女王**:墓穴深处的育母,产卵守墓。
- **F15 吸血鬼领主**:被深渊腐化的旧贵族,嗜血求生。
- **F20 远古巫妖**:**守印者军团的统帅**,为永守封印而转生不死,如今已疯——他记得创世者,却忘了为何而守。
- **F25 龙皇**:最后一只扭曲的守护巨兽,守着通往深渊本体的入口。
- **F30 利维坦**:深渊本体渗入后诞生的巨兽。
- **F35 虚空君主**:封印裂纹中渗出的实体。
- **F40 创世者**:见核心设定。悲剧守护者,求死。
- **守渊人**:见核心设定。跨层追猎的宿敌(非固定层)。

## 力量与物品

### 元素(Elements / 元素)
封印的**五道纹理**:火(炉)/ 冰(渊)/ 雷(纹)/ 暗(渊泄漏)/ 圣(创世者意志)。法术 = 短暂借用纹理之力;元素生物 = 泄漏具象。

### 圣物(Relics / 圣物)
封印的**碎片**与创世者昔日的**随身之物**。每件都带着被遗忘的记忆碎片(→ 圣物图鉴 lore 展开)。boss 必掉、精英常有。

### 职业下探动机(Classes / 职业)
- **战士**:为赎罪/荣耀(曾是逃兵?或寻亲)。
- **盗贼**:为深渊深处的传说宝藏。
- **法师**:为地表禁绝的深渊知识(危险的好奇)。
- **圣骑士**:为净化使命(被教会派出,但教会真的懂深渊吗?)。
每职业的动机可在典籍「下探者档案」展开,甚至影响开局圣物/对话。
